## “便宜”便宜在哪，又贵在哪

$2.99 一个月能买到 1 核 512MB，成本是从几个地方省出来的，知道这几点，才不会对它的表现有错误预期。

**资源是共享的，标称频率是上限。** 这个价位段的 vCPU、内存、磁盘 IO 都可能被超售，单核跑分好看不等于晚高峰不卡。用 `uptime` 看 load、用 `top` 看 steal time，比看商家给的跑分图有用。

**流量是硬配额，不是“不限”。** 500GB 到 10TB 是明写的额度，超出之后的处理规则（限速、停机还是按量计费）价格页没有写，得去看条款。真正的“不限流量”通常附带公平使用政策，超过“合理使用”一样被限速。

**SLA 和工单响应不会写进价格页。** 这个价位段不要指望赔偿条款，把它当成可以随时替换的节点更实际。真要放关键业务，选有明确 SLA 和合规资质的商家，别在这一档上省。

**功能按需收费，备份是少见的例外。** 额外 IP $3/月、更高配置按档加价，都是正常做法；Evoxt 把每周异地备份做成了免费项，这是它相对同价位商家的一个实际差异。

**年付换现金流。** 长期套餐的折扣本质是商家提前拿到钱。第三方测评提到 Evoxt 年付自带约 10% 折扣，官方价格页没有标注，结账页选年付时才看得到实际数字。

## 拿到机器先做这几件事

便宜 VPS 的真实表现，开机后一小时内就能测出大概。这套动作跟品牌无关，换任何一家都适用。

1. **测连通性，挑晚高峰**。从你实际使用的网络跑 `ping`、`mtr`、`traceroute`，重点看 20:00–23:00 的抖动和丢包。白天 30ms、晚上 300ms 的线路，标称带宽再大也没意义。
2. **压磁盘看稳定性，不看峰值**。`fio` 做 4K 随机读写，连续跑几轮，观察 IOPS 是否一路下滑。写入 50–200MB/s、4K 随机 5–20k IOPS 是这类机器的常见区间，明显低于这个数就是邻居在抢盘。
3. **跑 10–30 分钟满核**。`stress-ng --cpu 1 --timeout 30m`，看频率是否被压到基频、有没有温度节流的迹象。这条直接决定“最高 6.0 GHz”对你意味着什么。
4. **对带宽做实测**。`iperf3` 加一次真实文件下载，跟套餐标称的流量配额和端口速率对一遍，顺便确认常用端口没有被封。
5. **备份加一层**。Evoxt 的每周异地备份是免费的，但 RPO 是一周，重要数据自己用 `restic` 或 `rsync` 再推一份到别处，别把恢复希望全押在商家身上。
6. **安全基线**。SSH 密钥登录、禁用密码、改默认端口、开 `ufw` 只放行 22/80/443、装 Fail2ban。再做一次 IP 信誉检查，看这个 IP 有没有进过邮件或反垃圾黑名单，有问题立刻开工单换。

## 什么情况下不该买这一档

- 金融、支付类业务，或要求 99.99% 可用性的系统
- 重 I/O 的数据库、消息队列，磁盘 IO 会被邻居拖死
- 实时语音、视频、交易撮合这类对延迟抖动敏感的场景
- 需要 ISO 27001、SOC 2 等合规审计的业务
- 长时间满核的编译、转码、CDN 回源洪峰

这些需求不是加钱换更高档能解决的，同一台宿主机上的资源争抢和缺少 SLA 赔偿，换到 VM-16 一样存在。
